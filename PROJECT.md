# Maze Game

## What it is
This is a game where you control a tiny square and you go through randomly generated mazes forever.
It's cool because it's randomly generated and infinite, so every maze is different.

## How to run it
Run python final_project.py in the terminal, then open port "Game Desktop (6080)" in the browser to see the game window. Use the arrow keys or WASD to move.

## How it works
The code uses the Pygame library and creates sprites for the player and walls. The hardest part of the code was probably randomly generating the walls. The code works by randomly building the walls by using depth first search.
